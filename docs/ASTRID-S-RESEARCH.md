## Import into your local WordPress site

Your Windows WordPress database is separate from the cloud development database. Code changes alone do not update its records.

1. Back up your local database before importing content.
2. Download the updated project from GitHub once this change has been uploaded. From the new download, copy **only** `plugin/` into the `plugin/` folder of your existing project, replacing the plugin code files. Keep your existing `.env` and Docker volumes. Do not replace your whole installation or run a database reset.
3. In WordPress administration, open **Artists → Research collections**.
4. Review the candidate list, then select **Create missing research drafts**.
5. Open the artist and song records from that screen. Existing records are retained without modifications; missing records are created as drafts and keep the Demo flag. The existing Hurts So Good demo is reused if its artist link matches Astrid S.

The operation is repeatable. It preserves edited/imported records, including records moved to Trash. It never installs automatically, fetches remote data, publishes research drafts, changes another artist's same-titled song, or overwrites existing recommendations. Add reviewed songs to the artist's Recommended songs field when ready.

The researched biography, source-linked listening notes, verified Spotify links, and final ranked/curated ten-song selection remain outstanding until sources can be read and checked.
